# Linum

**Локальна ШІ-студія зображень з чат-помічницею. Усе працює на вашому комп'ютері: без хмари, без акаунтів, без інтернету після встановлення.**

[English](README.md) · **Сайт: [glib165.github.io/Linum](https://glib165.github.io/Linum/)**

## Завантаження

Linum можна завантажити двома способами:

1. **Повна версія, з сайту** (Windows, 36 ГБ): відкрийте [glib165.github.io/Linum](https://glib165.github.io/Linum/) і натисніть **«Завантажити Linum»**. Усе вже всередині: Python, Ollama, Gaia і всі моделі. Розпакуйте архів і двічі клацніть ярлик **Linum** у папці Linum. Нічого не треба встановлювати, інтернет після завантаження не потрібен. При першому запуску Linum сам додасть ярлик на стільницю і в меню «Пуск».
2. **Мала версія, з GitHub** (Windows і Mac, 1 МБ): відкрийте [останній реліз](https://github.com/Glib165/Linum/releases/latest) і в розділі Assets завантажте **Linum-1.8.zip**. Розпакуйте і запустіть встановлювач: він сам завантажить Python, Ollama і моделі (див. [Встановлення на Windows](#встановлення-на-windows) або [на Mac](#встановлення-на-mac)).

Ви розмовляєте з **Gaia**, помічницею Linum, будь-якою мовою. Вона відповідає на питання, малює нові картинки, змінює ваші фото і вчиться на власних помилках.

## Можливості

**Розмова і малювання**
- Розмова з Gaia будь-якою мовою: вона відповідає тією мовою, якою ви пишете.
- Три художні моделі: **Fornax** (швидка, ~7 с на картинку), **Gaia** (збалансована), **Cygnus** (фотореалістична).
- Стилі (Кіно, Аніме, Олійний живопис, Піксель-арт та інші) і **свої стилі**, описані звичайними словами.
- Чотири **рівні міркувань** (Низький, Середній, Високий, Ультра): від миттєвої відповіді до роздумів і перевірки готової картинки.

**Зміна фото звичайним проханням**
- Надішліть своє фото (кнопка «+» або Ctrl+V).
- **Прибрати** предмет: «прибери ту штуку внизу ліворуч».
- **Перефарбувати** точно, по пікселях, зі збереженням текстури й тіней: «поміняй кольори місцями», «зроби робота червоним».
- **Додати** предмет: «додай кота на диван».
- Змінити все фото: пору року, час доби, стиль.
- Змінені фото зберігають **оригінальний розмір**, а все поза зміною лишається недоторканим.
- **Збільшення ×2** моделлю Real-ESRGAN.

**Gaia вчиться**
- Агент-**Критик** перевіряє готові картинки і виправляє помилки: перефарбовує неправильні кольори або перемальовує, а потім лишає кращий варіант.
- **Зошит уроків**: Gaia вчиться у Критика і з ваших оцінок (палець угору чи вниз) і читає уроки перед кожною картинкою.
- **Тренування**: агенти самі придумують завдання, малюють, перевіряють себе і записують уроки.
- **Пам'ять**: Gaia пам'ятає ваше ім'я і смаки між чатами. Усе, що вона пам'ятає, видно і можна видалити.

**Програма**
- Чати: закріпити, перейменувати, проєкти, розділи, архів, «відкрити в новому вікні».
- Інтерфейс українською, англійською і російською; світла й темна тема.

## Що потрібно

**Windows**
- Windows 10 або 11.
- Відеокарта NVIDIA з **6 ГБ** відеопам'яті або більше (Linum розроблено на GTX 1660 Super).
- Рекомендовано **32 ГБ** оперативної пам'яті: мозок Gaia (Gemma 4, 26B) частково працює з неї.

**macOS** (експериментально, ще не перевірено на справжньому Mac)
- Mac з чипом **Apple** (M1, M2, M3, M4 або новіший). Mac на Intel не підтримуються.
- **32 ГБ** пам'яті для повної Gaia 3.7; з 16 ГБ користуйтеся рівнем міркувань **Низький**.

**Для обох**
- Близько **35 ГБ** вільного місця для моделей.
- Інтернет під час встановлення. Заздалегідь нічого ставити не треба: встановлювач сам завантажить Python і [Ollama](https://ollama.com).

## Встановлення на Mac

1. Завантажте **Linum-1.8.zip** з [останнього релізу](https://github.com/Glib165/Linum/releases/latest) і розпакуйте.
2. Двічі клацніть **`install.command`** (якщо macOS не дає: права кнопка, «Відкрити», «Відкрити»). Він сам завантажить Python, Ollama, бібліотеки й моделі (разом ~30 ГБ, це надовго) і додасть **Linum** у папку «Програми».
3. Запускайте Linum з «Програм», Launchpad чи Spotlight.

## Встановлення на Windows

1. Завантажте **Linum-1.8.zip** з [останнього релізу](https://github.com/Glib165/Linum/releases/latest) і розпакуйте.
2. Двічі клацніть **`install.bat`**. Він сам завантажить Python, Ollama, бібліотеки й моделі (разом ~30 ГБ, це надовго) і створить **ярлики Linum** на стільниці й у меню «Пуск».
3. Запускайте Linum ярликом.

Якщо завантаження обірвалося, просто запустіть встановлювач ще раз: він продовжить з місця, де зупинився.

<details>
<summary>Встановлення вручну</summary>

```
python -m venv .venv
.venv\Scripts\activate
pip install torch==2.14.1 torchvision==0.29.1 --index-url https://download.pytorch.org/whl/cu126
pip install -r requirements.txt
python scripts\download_models.py
ollama pull gemma4:26b
ollama create gaia-3.7 -f models\llm\Gaia.Modelfile
ollama pull gemma4:e4b-it-qat
python main.py
```
</details>

Якщо при запуску ярликом щось піде не так, помилку буде записано в `logs/linum.log`.

## Моделі та їхні ліцензії

Власний код Linum поширюється за [ліцензією MIT](LICENSE). Моделі створили інші люди, і вони мають свої ліцензії. Їх завантажує встановлювач, у цьому репозиторії їх немає.

| Модель | Що робить у Linum | Ліцензія |
|---|---|---|
| [DreamShaper 8](https://huggingface.co/Lykon/DreamShaper) | Художня модель «Gaia», а з LCM-LoRA «Fornax» | CreativeML Open RAIL-M (див. сторінку моделі) |
| [Realistic Vision V6.0](https://huggingface.co/SG161222/Realistic_Vision_V6.0_B1_noVAE) | Художня модель «Cygnus» | CreativeML Open RAIL-M |
| [LCM-LoRA SD 1.5](https://huggingface.co/latent-consistency/lcm-lora-sdv1-5) | Прискорює Fornax до 6 кроків | OpenRAIL++ |
| [sd-vae-ft-mse](https://huggingface.co/stabilityai/sd-vae-ft-mse) | Декодер кольорів для Cygnus | MIT |
| [Gemma 4](https://ollama.com/library/gemma4) (26B і E4B) | Мозок Gaia: розмова, рішення, Критик, Вчитель | Apache 2.0 |
| [CLIPSeg](https://huggingface.co/CIDAS/clipseg-rd64-refined) | Шукає предмет за назвою | Apache 2.0 |
| [SAM ViT-B](https://huggingface.co/facebook/sam-vit-base) | Точно обводить контур предмета | Apache 2.0 |
| [Real-ESRGAN x4plus](https://github.com/xinntao/Real-ESRGAN) | Збільшення фото | BSD 3-Clause |
| [opus-mt uk-en](https://huggingface.co/Helsinki-NLP/opus-mt-uk-en), [ru-en](https://huggingface.co/Helsinki-NLP/opus-mt-ru-en) | Перекладає запити, коли Gaia не запущена | Apache 2.0, CC BY 4.0 |

Ліцензія CreativeML Open RAIL-M дозволяє вільно використовувати створені картинки, зокрема комерційно, але забороняє використовувати моделі для низки шкідливих цілей. Перед комерційним використанням прочитайте ліцензію на сторінках моделей.

## Будова проєкту

| Шлях | Що це |
|---|---|
| `main.py` | Запускає програму |
| `config/config.py` | Моделі, стилі, рівні міркувань, версія |
| `src/frontend/` | Вікно: чати, налаштування, віконце рівня, переклади (`i18n.py`) |
| `src/ai/generator.py` | Малювання і зміна фото (Stable Diffusion 1.5 через diffusers) |
| `src/ai/brain.py` | Gaia: розмова, рішення, Критик, Вчитель |
| `src/ai/segmenter.py` | Пошук предметів (CLIPSeg + SAM) |
| `src/ai/recolor.py` | Точне перефарбування |
| `src/ai/upscaler.py` | Збільшення фото (Real-ESRGAN) |
| `src/ai/lessons.py`, `src/ai/trainer.py`, `src/ai/memory.py` | Самонавчання і пам'ять |
| `models/llm/Gaia.Modelfile` | Особистість Gaia для Ollama |
| `scripts/` | Завантаження моделей, ярлики, невеликі експерименти |
